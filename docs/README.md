# Documentation

This directory contains documentation for the Windwatcher client, independently
of the [Windwatcher server](https://github.com/OtavioGonzaga/windwatcher).

The repository currently implements the shared web/native bootstrap and HTTP foundation,
not a functional messaging client. No client releases are available yet.

- [Development](development.md): toolchain, validation, native smoke and limitations.
- [Architecture](architecture.md): implemented boundaries and bootstrap security.
- [HTTP transport](network-transport.md): consumer boundary, error/security behavior and native smoke.
- [API contract](api-contract.md): released source, snapshot provenance and offline type generation.
- [Architectural Decision Records](adr/README.md): decision-record policy and template.
- [Brand assets](../public/brand/README.md): supplied artwork and source inventory.
